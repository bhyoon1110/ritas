보고서 정보·결과 요약

PPT·미리보기는 분석 결과 요약 → 상 동정 (Phase Identification) & WPPF 정량 (Phase Fraction) 결과 → 상 동정 (Phase Identification) 결과의 3가지 양식만 사용합니다. 요약은 페이지당 3시료, WPPF 결과는 시료당 한 번, 상 동정 결과는 페이지당 최대 2시료로 배치합니다. 긴 상 목록의 나머지 행은 상 동정 양식으로 이어지며 정량 그래프는 반복하지 않습니다. 페이지 선택기의 시료명과 상 표의 행 범위로 구분할 수 있습니다. 해당 자료가 없는 유형은 생략합니다.

보고서 시료와 순서

표시 시료명은 보고서에만 적용됩니다. PDF 내부 이름과 측정 데이터는 유지합니다.

특이사항 생성(LLM 연결)

모델이 근거 후보마다 특이사항 문장을 씁니다. 문장의 수치와 상 이름은 그 후보의 원자료와 대조하고, 맞지 않는 문장은 원자료 템플릿 문장으로 둡니다. 최종 문장은 검토 후 사용하세요.

모델을 자동 설치하지 않습니다. localhost/loopback 서버만 연결합니다. 모델 미설정·연결 실패·응답 검증 실패 시 규칙 기반 후보로 돌아가며 사용자 수정 문장은 보존합니다.

보고서 저장

출력하기 전에 편집 내용을 자동으로 저장합니다. 전달 ZIP에는 보고서(PDF·PPTX·HTML), 오프라인 뷰어, 원본 PDF·TXT가 들어갑니다.

뷰어 보기 전달
