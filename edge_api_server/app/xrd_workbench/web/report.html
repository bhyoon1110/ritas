보고서 정보·결과 요약

표지 다음에 분석 결과 요약, 상 동정·WPPF 정량 결과, 상 동정 결과를 배치합니다. 요약은 내용량에 맞춰 시료별 결정상 정보를 2열로 배치하고 다음 페이지로 이어집니다. 특이사항은 상 분류의 미량상·추정상 여부로만 자동 생성하며, 해당 사항이 없으면 공란입니다. WPPF 원문 정량값은 표로 표시합니다. 미리보기·PPT·PDF는 같은 양식을 사용합니다.

표지 · 분석 이력 정보

실제 측정·검토 기록을 입력하세요. 미기재는 자동 추정하지 않으며 검토자 기재는 전자서명이 아닙니다.

보고서 시료와 순서

표시 시료명은 보고서에만 적용됩니다. PDF 내부 이름과 측정 데이터는 유지합니다.

설정 프리셋

그래프·정량 표·분류 기준 문구를 이름 붙여 저장하고 다른 보고서에 적용합니다.

검토 문장 생성(LLM 연결)

모델이 근거 후보마다 보존용 검토 문장을 씁니다. 보고서 요약의 특이사항에는 사용하지 않습니다. 문장의 수치와 상 이름은 그 후보의 원자료와 대조하고, 맞지 않는 문장은 원자료 템플릿 문장으로 둡니다. 최종 문장은 검토 후 사용하세요.

모델을 자동 설치하지 않습니다. localhost/loopback 서버만 연결합니다. 모델 미설정·연결 실패·응답 검증 실패 시 규칙 기반 후보로 돌아가며 사용자 수정 문장은 보존합니다.

보고서 저장

출력하기 전에 편집 내용을 자동으로 저장합니다. 전달 ZIP에는 보고서(PDF·PPTX), 오프라인 그래프 뷰어, 원본 PDF·TXT가 들어갑니다. HTML 형식 보고서는 포함하지 않습니다. 수정 비밀번호가 없으면 일반 편집 가능한 PPTX로 저장됩니다. 비밀번호를 설정한 경우에만 지원하는 PowerPoint에서 편집을 제한합니다. 보고서는 PDF 또는 PPTX로 확인하고, 그래프 확대·축소는 뷰어.html을 브라우저로 열어 사용하세요.

뷰어 보기 전달

보고서에 포함한 시료만 전달하며, 의뢰자는 뷰어에서 표시·숨김을 바꿀 수 있습니다.
