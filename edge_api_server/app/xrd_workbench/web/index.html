처음이신가요? 사용 방법
  1. 왼쪽 위 범례의 체크로 시료와 결정상을 켜고 끕니다.
  2. 시료 간 세로 간격으로 그래프를 겹치거나 위아래로 벌립니다 (0은 겹쳐 보기).
  3. 마우스 휠은 확대, 왼쪽 드래그는 영역 확대, 오른쪽 드래그는 이동, 더블클릭은 처음 범위로 돌아갑니다.
  4. 한 시료만 자세히 보려면 시료 하나씩 보기를 누르고 시료를 고르세요.
  5. 그림은 현재 이미지 내보내기로 저장합니다.

파일을 한 번에 선택한 뒤 시료명과 역할을 확인하세요. 오타는 연결표에서 수정할 수 있습니다.

Raw TXT 입력 형식

각도(X)와 강도(Intensity) 두 숫자 열을 공백·탭·쉼표로 구분합니다. 각도는 중복 없이 증가해야 하며 설명 행은 #으로 시작합니다.

#Intensity_unit=cps
10.00 125
10.02 138
10.04 142

단위·축 정보는 원자료 또는 연결표에서 확인하세요. 임의 정규화·정렬·삭제하지 않습니다.

원본 파일명과 자료는 유지됩니다.
