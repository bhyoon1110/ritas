처음이신가요? 사용 방법
  1. 왼쪽 위 범례의 체크로 시료와 결정상을 켜고 끕니다.
  2. 수평 조절 슬라이드바로 그래프를 겹치거나 위아래로 벌립니다 (가운데가 겹쳐 보기).
  3. 마우스 휠은 확대, 왼쪽 드래그는 영역 확대, 오른쪽 드래그는 이동, 더블클릭은 처음 범위로 돌아갑니다.
  4. 한 시료만 자세히 보려면 시료 하나씩 보기를 누르고 시료를 고르세요.
  5. 그림은 현재 이미지 내보내기로 저장합니다.
