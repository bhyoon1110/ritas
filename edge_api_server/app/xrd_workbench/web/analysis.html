원본 PDF·이미지는 유지됩니다. 수정값은 사유와 함께 저장하며, 검토 완료 표만 후속 분석에 적용합니다. 직접 입력 정량은 출처·확인을 등록하고 사용할 값 목록을 선택하세요.

PDF에서 읽은 내용을 소제목 단위로 모았습니다. 여러 쪽에 나뉜 표는 하나로 합쳐 보여 줍니다. 행을 누르면 그 행이 있는 원본 쪽을 엽니다. 값을 고치려면 쪽별 표 · 수정에서 해당 표를 여세요.

행 제외는 검토 완료 시 적용됩니다. 인식된 헤더는 고정합니다. 미인식 표도 저장하며, 확인되지 않은 구조는 분석값으로 생성하지 않습니다.
