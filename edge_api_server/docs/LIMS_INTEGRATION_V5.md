# LIMS v5 연계 (2026-11-06)

FTIR·Raman·TEM·XRD 의뢰 선택 화면에서 LIMS 실시간 조회를 선택하고 자산번호와 시험상태로 검색할 수 있다. 실제 장비를 지정할 때는 LIMS 자산번호를 입력한다. 미완료 시험은 `1,3,5,7`이고, 해당 장비로 수행 가능한 시험이 검색된다. 취소(0), 완료(9)를 포함한 전체 조회도 가능하다. 저장된 의뢰 목록에는 자산번호가 없으므로 장비별 검색에는 실시간 조회를 사용한다.

의뢰에 여러 시험이 있으면 선택한 행의 시험방법코드를 문서 등록(API-2)까지 전달한다. 과거 미리보기에 프로젝트명만 저장돼 시험방법코드를 확인할 수 없는 경우에는 편집 화면에서 의뢰와 시험을 다시 선택해 저장한다. [의뢰조회 조건 및 예시](LIMS_REQUEST_FILTERS_V5.md)

보고서 메일의 받는 사람은 의뢰번호로 결정한다. Python은 실시간 미리보기에서 내부 Spring에 의뢰번호를 전달하고, Spring은 LIMS 의뢰 목록의 `reqResultNo`로 `GET /api/alarm/reqUserEmail/{reqResultNo}`를 호출한다. 발송 시 Spring이 확인한 주소를 사용한다. 참조·비밀참조, 제목, HTML 본문과 첨부 ZIP은 기존 보고서 전송 흐름을 따른다. 주소가 누락됐거나 의뢰 내부번호를 한 건으로 특정할 수 없으면 임의 주소로 발송하지 않는다.

의뢰 실시간 조회와 수신자 미리보기는 `RIST_LIMS_REQUESTS_ENABLED=true`, `RITASAX_LIMS_REQUEST_PROXY_ENABLED=true`와 기존 내부 키 설정을 사용한다. 위존은 11월 6일 의뢰조회·필터와 기존 API-2의 개발 서버 반영을 회신했다. API-2 신규 등록은 201, 중복 등록은 200과 `duplicate=true`다. 폴링 및 메일 재시도와 파일 보관 설정은 [v4 가이드](LIMS_INTEGRATION_V4.md)를 따른다.

11월 9일 위존 회신에 따르면 수신자 API는 의뢰조회와 같은 연계 토큰을 사용한다. 등록된 주소가 없거나 `reqResultNo`가 존재하지 않으면 LIMS는 HTTP 200과 빈 본문을 반환한다. Spring은 주소 없음으로 처리해 Edge 미리보기에 내부 HTTP 404를 전달하고, 신규 발송은 SFTP 업로드 전에 중단한다. 주소가 있는 경우에는 회신받은 시험용 의뢰로 실제 응답을 확인한다. [로컬 통합시험](../tests/integration/README.md)은 합성 주소를 사용한다. 첨부 발송 시험에는 SFTP 접속정보와 첨부 용량 기준 확인이 필요하다.
