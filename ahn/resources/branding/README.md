# 보고서 원본 브랜드 이미지

사용자가 제공한 `XRD_분석보고서_A4.pptx`의 슬라이드 마스터 이미지이며,
저장소의 `edge_api_server/app/xrd_workbench/render/assets/posco_xrd_a4.pptx`와 동일한 바이트다.

- `posco-banner.jpeg`: 원본 `ppt/media/image1.jpeg`. 하단 88.460%를 잘라 상단 띠를 표시.
- `rist-logo.png`: 원본 `ppt/media/image2.png`. 원본 크기 비율 유지.

`ahn.report_branding`이 TEM과 FTIR/Raman의 기존 보고서 생성기에 공급한다.
외부 URL이나 XRD 실행 모듈에 의존하지 않으며 원본 PPT의 시료 데이터는 포함하지 않는다.
